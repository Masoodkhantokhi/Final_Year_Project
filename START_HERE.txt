START HERE  (Student Wellbeing Intelligence Platform)

PREREQUISITES (Run Once)
  1. Python 3.12 (from python.org - tick "Add python.exe to PATH")
  2. Node.js (v18 or higher from nodejs.org)

RUNNING ON WINDOWS
  Double-click  START_DASHBOARD_WINDOWS.bat
  Your browser will automatically open at: http://localhost:3000

RUNNING ON MAC / LINUX
  Open Terminal in this project folder and type:
  bash START_DASHBOARD_MAC_LINUX.sh

RUNNING IN VS CODE
  1. In the terminal, run:
     node start.js
  2. Open http://localhost:3000 in your browser.

STOPPING THE APP
  Close the command window or press Ctrl+C in the terminal.

FOR REPORT & VIVA
  The research notebook (Mental_Health_Assessment_System.ipynb) contains the model
  training, feature audit, baseline comparisons, and cross-validation metrics.
