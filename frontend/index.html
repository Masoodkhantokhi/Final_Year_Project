System Methodology & Architectural Design

The Student Wellbeing Assessment System uses a modern full-stack architecture combining a Node.js / Express API gateway with a dedicated Python ML microservice running scikit-learn and SHAP TreeExplainer.

Machine Learning Pipeline: The core estimator is a tuned RandomForestRegressor combined with a ColumnTransformer preprocessing pipeline that one-hot encodes categorical dimensions (Academic Level, Social Media Purpose) while maintaining numeric habit continuity.

Explainable AI (XAI): Rather than acting as a black-box model, each individual inference is explained via SHAP (SHapley Additive exPlanations) values. The model decomposes feature interactions into exact points added or subtracted relative to the global expected baseline score.

Ethical AI by Design: Demographic factors such as nationality, gender, and age were deliberately excluded from model training. Lifestyle and mental wellbeing advice should never be prejudiced based on immutable demographic identity, only actionable student behaviors.
